# Nand2Tetris course starter projects

These 249 files are unchanged copies of the supplied Nand2Tetris projects,
including folders 0 through 13. Student exercises are intentionally incomplete.

Files > Create course workspace copies this bundle into a new writable local
folder. Save changes only that copy. On Android, export important work before
uninstalling the app. Use Files > Export workspace copy to share saved work.
The manifest records every original project file, including platform metadata.

The separate examples folder contains new NandStudio demonstrations, not course
solutions. Bundled projects do not establish complete simulator feature parity.
