# Supplied Jack OS VM files

These eight compiled VM files are copied unchanged from the uploaded Nand2Tetris
software distribution, tools/OS. They accompany The Elements of Computing Systems
by Noam Nisan and Shimon Schocken (MIT Press).

built-in services and are not relicensed under NandStudio's GPL license.
Existing project-local VM files always take precedence: the add-OS action skips
existing names, including empty student implementations. Preserve this notice
